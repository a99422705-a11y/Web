# TaskNest Front-End Development Assignment

**Candidate:** MD Asif  
**Company:** Sankar Group  
**Project:** TaskNest, a sample SaaS productivity and task-planning landing page

## Overview
TaskNest is a responsive landing page concept for a simple productivity SaaS product. It introduces the product, explains its features and workflow, presents two pricing plans, and lets visitors submit a demo sign-up request through a front-end form.

## Technologies used
- HTML5
- CSS3 (Grid, Flexbox, media queries)
- Vanilla JavaScript

## Project files
- `index.html` - page structure and content
- `style.css` - layout, visual design, and responsive styling
- `script.js` - mobile navigation, modal, form validation, and success state
- `screenshots/` - desktop and mobile layout previews

## How to run locally
1. Download and extract the ZIP folder.
2. Open `index.html` in a modern web browser.
3. No installation, build command, backend, or database is required.

## Functional features
- Navigation links scroll to the matching page sections.
- Mobile menu opens and closes on small screens.
- Get Started and pricing buttons open the sign-up form.
- The form validates the name and email address.
- A success message appears after valid form submission.
- The layout adapts to mobile and desktop screen widths.

## Design choices and challenges (submission explanation)
I created TaskNest as a clean productivity platform for students and small teams. I used a soft purple palette, clear typography, and generous spacing to make the page easy to read. The landing page is divided into clear sections for features, workflow, pricing, and contact. CSS Grid, Flexbox, and media queries help the layout adapt to desktop and mobile screens. JavaScript controls the mobile navigation and sign-up modal. I also added basic form validation and a success message so the main call to action has a working interaction. The main challenge was keeping the dashboard-style hero illustration readable while making the design responsive.

## Notes
This is a front-end demonstration. The sign-up form displays a local success message and does not send data to a server. The email address in the footer uses the reserved `.example` domain as placeholder contact information
